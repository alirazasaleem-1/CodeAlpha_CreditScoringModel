# What is Credit Scoring?
Credit scoring is a process of predicting whether a person is likely to replay a loan based on their financial and personal information. 

# What type of Machine Learning Problem is this?
Machine Learning -> Supervised Learning -> Classification -> Binary Classification

# What are the Features?

Examples from our dataset:

person_age
person_income
person_emp_length
loan_amnt
loan_int_rate
loan_intent
loan_grade
cb_person_default_on_file

# What is the Target?
loan_status
